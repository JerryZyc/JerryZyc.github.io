## TL;DR
ETH RSL 提出的统一 RL 框架，通过 **注意力机制的地图编码器 (AME-2)** 实现了四足/双足机器人的敏捷与泛化 locomotion。核心思路是将显式地图与 RL 控制器结合，用 global terrain context 做 attention 来加权 local features，同时配套一个**轻量级、带不确定性的学习建图管线**。在 ANYmal-D 和 TRON1 上验证了 parkour + 未知地形泛化。

## 问题定义与假设

感知 locomotion 的核心矛盾：
- **敏捷性方法**（端到端 sensorimotor）：动作灵活但泛化差、不可解释
- **泛化方法**（显式地图 + RL）：泛化好但敏捷性受限，对建图质量和更新率敏感
- **现有瓶颈**：occlusion 下的稀疏落脚点、sim-to-real 地图不一致

**假设**：如果设计一个可解释、带不确定性的地图编码器，同时让 RL 策略学会根据地形上下文注意力地关注关键区域，就能同时实现敏捷和泛化。

## 方法

### 1. AME-2 编码器（核心创新）

相比前作 AME-1，AME-2 **额外计算 global features** 并用它们来加权 local features：

```
地图输入
  ├─ CNN ──→ local features (逐像素)
  ├─ MLP + max pool ──→ global features (全局地形上下文)
  └─ MHA (global + 本体感知 → query, local → key/value)
       └─→ attention-weighted local features
            └─ 与 global features 拼接 → map embedding → MLP → action
```

**关键设计**：attention 权重由 global terrain context 和 proprioception 共同决定，使策略能根据不同地形**自适应**地关注不同区域。

### 2. 学习建图管线

传统建图的替代方案：
- **输入**：深度相机点云 → 投影到 local height grid
- **轻量 U-Net**：预测 elevation + 不确定性（log-variance）
- **Probabilistic Winner-Take-All 融合**：用 odometry 将局部预测融合到全局地图，避免对遮挡区域过度自信
- **训练数据**：54M 帧合成数据（raytracing + 随机噪声/Occlusion 增强）

### 3. 训练框架

**Teacher-Student**：
- Teacher 策略：使用 ground-truth 地图 + 完整本体感知
- Student 策略：使用学习建图管线，受 teacher 监督 (action distillation + representation loss)
- Asymmetric Actor-Critic：actor 用 AME-2，critic 用 MoE（更高效）

**奖励设计**（统一适用于四足/双足）：
- Task rewards: position tracking + heading tracking + moving + standing
- 无显式落脚点奖励 → 鼓励 emergent whole-body contacts

## 实验设置

- **机器**：ANYmal-D (四足) + LimX TRON1 (双足)
- **训练**：Isaac Gym, PPO (RSL-RL), 8×RTX 4090
- **ANYmal**：60 RTX-4090-days, `36×14` 地图 @ 8cm 分辨率
- **TRON1**：30 RTX-4090-days, `18×13` 地图 @ 8cm 分辨率
- **部署**：ONNX Runtime, ~2ms 推理, ~5ms 建图

## 结果与消融

### 主要结果
- 四足 Parkour：跳跃、攀爬、稀疏地形行走
- 双足操作：敏捷 maneuvers
- 对传感器遮挡、噪声的鲁棒性显著优于 baseline
- 未见过的复杂地形上泛化能力强

### 消融关键发现
| 消融项 | 结论 |
|--------|------|
| AME-2 vs AME-1 | 全局特征 + attention 显著提升泛化 |
| MoE vs AME actor | MoE 拟合强但不泛化 |
| 学习建图 vs 传统建图 | 不确定性感知提升 occlusions 下表现 |
| NLL vs β-NLL loss | β-NLL 减少过估计不确定性 |

### Emergent 行为
- Active perception：机器人主动调整视角来观察盲区
- Loco-navigation：locomotion + 导航的行为融合
- Whole-body contact：爬坡时利用膝盖支撑
- Impact reduction：借鉴生物力学阈值自动学习缓冲

## 优点与局限

### 优点
- **统一框架**：四足/双足共享训练设置，填补了敏捷与泛化之间的 gap
- **可解释性**：attention 权重可可视化，展示策略关注区域
- **实用建图**：轻量、带不确定性、与仿真和真机一致，降低 sim-to-real gap
- **完整 ablations**：消融实验覆盖架构、建图、噪声各个方面

### 局限
- 训练成本高（ANYmal 60 GPU-days）
- 依赖深度相机，低光/透明表面效果未知
- Goal-reaching formulation 不直接适用于 velocity tracking 任务
- 仍然需要预先定义的地形课程；完全开放世界泛化尚未解决

## 复现清单
- 依赖：Isaac Gym, RSL-RL, Warp, ONNX Runtime
- 关键超参数：PPO clipping=0.2, entropy coeff=0.01, 见附录 C
- 建图模型：U-Net with gated residual, β-NLL (β=0.5)
- 注意事项：需要大规模并行仿真才能复现训练效果

## 如何用于我的项目
- **注意力机制的地图编码**：可借鉴到我的 Sim2Real 工作中，尤其是处理遮挡和稀疏地形
- **不确定性感知建图**：Probabilistic Winner-Take-All 思路可以推广到其他感知任务
- **统一奖励设计**：无任务特定奖励 + 稀疏地形 emergent 行为的思路值得尝试
- 可以考虑将 AME 编码器迁移到其他机器人形态（如人形）
